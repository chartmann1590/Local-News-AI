# Broadcast Feature

The Broadcast feature generates a video that summarizes the latest news and weather. The video includes a voiceover and captions.

## How it Works

The broadcast is generated by a background task that is triggered manually from the web UI. The task does the following:

1.  Fetches the latest news articles and weather forecast.
2.  Generates a script for the broadcast.
3.  Synthesizes the script into audio using the TTS service.
4.  Generates a video with the audio and a simple background.
5.  Generates captions from the transcript.

## Web UI

The Broadcast feature is accessible from the web UI. The "Broadcast" button in the header will open a new page where you can view the latest broadcast, and trigger a new one.

### Broadcast Page

The broadcast page has the following features:

*   **Video Player:** A video player to watch the latest broadcast.
*   **Caption Overlay:** Captions are displayed over the video.
*   **Caption Toggle:** A button to toggle the visibility of the captions.
*   **Transcript:** The full transcript of the broadcast is displayed below the video.
*   **Regenerate Broadcast:** A button to manually trigger a new broadcast.

## API

The Broadcast feature has the following API endpoints:

- `GET /api/broadcast/latest` — Get the latest broadcast metadata.
- `POST /api/broadcast/regenerate` — Trigger a new broadcast.
- `GET /api/broadcasts?page=1&limit=10` — List recent broadcasts.
- `GET /api/broadcast/{id}/transcript` — Fetch the transcript text.
- `GET /api/broadcast/{id}/srt` — Fetch SRT subtitles (for `<track>` captions).
